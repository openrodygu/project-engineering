# Downloads

Ready-to-open copies of the vault templates:

- [team-vault.zip](team-vault.zip)
- [personal-vault.zip](personal-vault.zip)

Each ZIP contains a top-level folder (`team-vault/` or `personal-vault/`) with the Markdown guides, the `.obsidian` configuration, the plugins, and the theme. Extract it and open that folder in Obsidian.

These are generated from `templates/`. When a template changes, rebuild the ZIPs so they do not drift. Use any zip tool and include hidden files, keeping the template folder as the top-level directory in the ZIP.

If you would rather not run the bundled plugins, see the zero-trust option in [templates/README.md](../templates/README.md#2-open-and-trust-the-vault).
