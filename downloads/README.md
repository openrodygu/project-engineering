# Downloads

Ready-to-open copies of the vault templates:

- [team-vault.zip](team-vault.zip)
- [personal-vault.zip](personal-vault.zip)

Each ZIP contains a top-level folder (`team-vault/` or `personal-vault/`) with the Markdown guides, the `.obsidian` configuration, one community plugin (dotpm or TaskNotes), and the Border theme. Extract it and open the inner folder itself (the one containing `_README.md` and `.obsidian`) in Obsidian.

If you would rather not run the bundled plugin, see the zero-trust option in [templates/README.md](../templates/README.md#2-open-and-trust-the-vault).
