## The design rules

- Start with one project.
- Adopt one practice at a time.
- Prefer artifacts over meetings.
- Keep the system small enough to maintain.
- Remove anything that produces no decision.

## The capstone exercise

1. Fill in the canvas for a real project.
2. Share it with one person.
3. Ask: “What is unclear or missing?”
4. Change one thing.
5. Use it for one week.
6. Review what happened.

## Done criteria

You are done when:

- The team can see the work.
- Each task has an owner and a next action.
- Decisions have a home.
- There is a weekly review.
- The system fits on one page.
