# Pick your first skill

Do not learn everything. Pick the skill that solves your current pain.

## Pain to skill

| If this is your pain… | Start with |
| --- | --- |
| Work is invisible or duplicated | [Project management](../guides/project-management/) |
| I need version control | [Git](../guides/git/) |
| I need to publish or collaborate on code | [Git services](../guides/git-services/) |
| I want a shared team vault | [Obsidian](../guides/obsidian/) |
| I need to review or propose changes | [Collaboration](../guides/collaboration/) |
| My team needs direction | [Team lead](../guides/team-lead/) |
| My own task list is out of control | [Self-management](../guides/self-management/) |

## Paths

### Project management only

Read [Project management](../guides/project-management/). Skip the other skills. Use your existing tools.

### Obsidian for project work

Read [Obsidian](../guides/obsidian/) and [Project management](../guides/project-management/). Copy the templates. Skip Git until you need it.

### Version control only

Read [Git](../guides/git/). Use your own project folder. Stop after local commits, branches, and merges if that is enough.

### Publish and collaborate

Read [Git](../guides/git/), then [Git services](../guides/git-services/), then [Collaboration](../guides/collaboration/). You will publish a repository, open an issue, and review a pull request.

### Lead a team

Read [Team lead](../guides/team-lead/) and [Self-management](../guides/self-management/). Use [Project management](../guides/project-management/) when you need the work system.

## How to choose

Ask three questions:

1. What is causing the most friction right now?
2. What artifact would reduce that friction?
3. Which skill produces that artifact?

Pick one. Do the quick start. Then decide whether to go deeper or move on.

## Try it

Write one sentence:

> My first skill is ______ because ______.

Then open that skill’s README and do **Do this now**.
