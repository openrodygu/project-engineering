# Personal task system

A personal task system is a trusted place to put work so your head can stop holding it. It does not need to be complex. It needs to be complete enough that you believe it.

## The minimum

One inbox, one task list, one calendar. That is enough.

- **Inbox** — where new items land before you decide what they are.
- **Task list** — where clarified actions live.
- **Calendar** — where committed time lives.

In the personal vault, TaskNotes is the task list and the calendar views come from Bases. The inbox can be a single note called `Inbox`.

## Why one system

When work lives in chat, email, sticky notes, and your head, you spend energy remembering instead of doing. A single system gives you one place to check and one place to trust.

The rule is not "use this app". The rule is: **if it is real, it goes in the system.**

## The properties that matter

TaskNotes tasks have a few fields that do most of the work:

| Property | Use it for |
| --- | --- |
| `status` | Open, In progress, Done |
| `scheduled` | When you plan to work on it |
| `due` | When it must be finished |
| `contexts` | Where or how you do it |
| `timeEstimate` | How long it takes, in minutes |
| `projects` | Which outcome it supports |

You do not need every field on every task. Use the ones that change your decision.

## Keep it honest

A task system loses value when it lies. That means:

- Close tasks when they are done.
- Cancel tasks you are not going to do.
- Reschedule instead of leaving overdue items to rot.
- Do not keep a second secret list.

A short list you trust beats a long list you ignore.

## Personal is not team

The personal vault is for your execution. Team commitments belong in the team vault, where the team can see them. When a personal task becomes team work, promote it by hand.

## Try it

Create an `Inbox` note and spend five minutes writing down everything on your mind: tasks, errands, worries, follow-ups. Do not organize it yet. Then open TaskNotes and create one real task from the list.
