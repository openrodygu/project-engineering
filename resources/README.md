# Resources

Reusable checklists, templates, and reference pages. They are plain Markdown and work without Obsidian.

## Checklists

Short lists you can run in a few minutes.

- [Project kickoff](checklists/project-kickoff.md) — start with the important decisions made.
- [Weekly review](checklists/weekly-review.md) — keep the board honest and pick next week.
- [Project close](checklists/project-close.md) — finish, archive, and learn.

## Templates

Copy, paste, and fill in.

- [Project brief](templates/project-brief.md) — the one-page plan.
- [Decision record](templates/decision-record.md) — the reasoning behind a choice.
- [Status update](templates/status-update.md) — a short update for the team or a stakeholder.
